# 🥝 KiwiForms

Una aplicacion para generar formularios y hojas de respuestas y solicitarlas a un listado de usuarios. Con gestion de cuentas, relaciones y varios tipos de preguntas en los formularios.

---

## 🥝 Sobre el proyecto

Este proyecto forma parte de **Kiwi Studio**, una iniciativa personal creada por **Miguel Ángel Callejo** con los siguientes objetivos:

- 📚 Aprender desarrollando proyectos reales  
- 🧠 Explorar nuevas tecnologías y herramientas  
- 🛠️ Publicar código abierto y gratuito  
- 🎮 Crear aplicaciones y videojuegos desde cero  
- 🚀 Construir un portafolio profesional transparente y verificable  
- 🧩 Crear soluciones prácticas a problemas y necesidades reales  

Este repositorio sirve tanto como **producto funcional** como **registro del proceso de desarrollo**.

🌐 Web oficial: **[kiwiprojectstudio.com](https://kiwiprojectstudio.com)**

---

## ✨ Características principales

- Formularios dinamicos
- Generacion de JSON
- Exportacion a PDF
- Gestión de cuentas de usuario
- Vinculación entre usuarios

---

## 🛠️ Tecnologías utilizadas

- **Lenguaje(s):**  Kotlin, PHP, JS
